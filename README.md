# codeX Discord Bot

بوت دسكورد لـ codeX: ترحيب، تذاكر، حماية، تسليم طلبات.

المتجر الفعلي على **رمز**: https://codex112.rmz.gg

## التشغيل المحلي

```bash
npm install
npm run bot
```

ضع المتغيرات في `.env.local` أو بيئة النظام (انظر `.env.example`).

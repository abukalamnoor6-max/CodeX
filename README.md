# codeX Store

متجر ويب لخدمات البرمجة (فايف إم + بوتات دسكورد) مع دفع PayPal / تحويل الراجحي / Apple Pay.

## التشغيل

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## الإعداد المطلوب منك

### 1) دسكورد (مهم)

1. افتح سيرفرك → إعدادات القناة اللي تبي الطلبات فيها
2. Integrations → Webhooks → New Webhook
3. انسخ الرابط وضعه في `.env.local`:

```
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...
```

كل طلب جديد يوصلك كرسالة Embed على الدسكورد.

### 2) PayPal

حسابك الحالي: `noorabukalam29@gmail.com`

للدفع **التلقائي** (الفلوس تنزل مباشرة):

1. ادخل [PayPal Developer](https://developer.paypal.com)
2. أنشئ App → انسخ Client ID و Secret
3. ضعهم في `.env.local`

بدون المفاتيح: الزبون يقدر يدفع يدوياً لبريدك ثم يضغط «أرسلت الفلوس».

> ملاحظة: حساب PayPal العادي (Personal) يستقبل تحويلات. للدفع الاحترافي + SAR يفضّل ترقية لـ **Business**.

### 3) تحويل الراجحي

الآيبان معروض في صفحة الدفع:

`SA5280204406341222121014`

الزبون يحوّل ويرسل رقم العملية → يوصلك على دسكورد للمراجعة.

### 4) Apple Pay

Apple Pay **ما ينربط مباشرة** من الموقع — تحتاج بوابة سعودية:

1. سجّل في [Moyasar](https://moyasar.com)
2. فعّل Apple Pay من لوحتهم
3. أضف المفاتيح في `.env.local`

بعدها زر Apple Pay في صفحة الدفع يشتغل.

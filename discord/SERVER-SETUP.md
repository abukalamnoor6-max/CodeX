## الرولات (من الأعلى للأسفل) + صلاحيات
1. `⭐ BOT` — عرض فقط (بدون برمشنز)
2. `〢 OWNER` — **Administrator**
3. `〢 TEAM CodeX` — إدارة رسائل، طرد/حظر/ميوت، تايم أوت، لوقات، تحكم صوت
4. `〢 Partner` — دعوات + ستريم + إيموجي خارجي + أولوية صوت
5. `〢 VIP CodeX` — ستريم + إيموجي خارجي + أولوية صوت
6. `〢 Premium Client` — ستريم + إيموجي خارجي
7. `〢 Client` — ستريم + إيموجي خارجي
8. `〢 Visitor` — تغيير اللقب فقط (+ أساس @everyone)
9. `〢 BOOSTER` — رتبة دسكورد المدارة (ما نعدّلها)
10. `@everyone` — شات/قراءة/مرفقات/صوت — بدون ثريدز وبدون Use Apps وبدون منشن everyone

لتطبيق الصلاحيات من جديد:
`node scripts/apply-role-permissions.mjs`

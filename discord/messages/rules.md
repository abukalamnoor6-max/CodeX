# 📜│القوانين

**قوانين سيرفر codeX**

1. **الاحترام أولاً** — ممنوع السب، التنمر، أو الإساءة لأي عضو أو للطاقم.
2. **ممنوع الإعلان** — لا تروّج لسيرفرات/متاجر أخرى بدون إذن الإدارة.
3. **الطلبات عبر التذاكر فقط** — لا ترسل طلبات خاصة لعشوائية الطاقم.
4. **لا احتيال / لا نصب** — أي محاولة نصب = بان فوري.
5. **لا مشاركة ملفات ضارة** — سكربتات خبيثة أو روابط مشبوهة ممنوعة.
6. **الخصوصية** — لا تشارك بيانات دفع أو معلومات شخصية في الشات العام.
7. **التقييمات** — التقييم بعد استلام الخدمة، وبأسلوب محترم.
8. **قرارات الإدارة نهائية** — في حال المخالفة يحق لنا التحذير أو الميوت أو البان.

بالبقاء في السيرفر فأنت توافق على هذه القوانين وعلى شروط متجر codeX.
